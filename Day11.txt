count(): Count the number of records.
sum(): Returns the total sum of numeric column.
avg(): returns the average value.
min(): returns the minimum value.
max(): returns the maximum value.

Clauses:
--------
-> In MySQL clauses are used to control how data is selected, filtered, grouped, sorted or modified in SQL Queries.
   Think of clauses like instructions given to the database. 

Where Clause
-------------
filter records based on specified conditions where clause can be used as comparision operators, logical operators.. etc operators.

syntax
-------
select column1, column2....
from table
where condition.

Group By Clause 
-----------------
the group by clause is used to group rows having the same values in one or more columns. It is commonly used with aggregate functions such as sum(), min(), max(), avg(), count().

syntax
-------
select column-name, aggregate_function(column-name)
from table
group by column_name;

Having Clause
--------------
The having clause is used to filter grouped records after group by clause. It is similar to where but it works on grouped instead of individual rows.

syntax
-------
select column-name, aggregate_function(column-name)
from table
group by column_name;
having condition;

order by
----------
the order by clause is used to sort the result set in ascending order(ASC) OR descending order(DESC)

asc-> Asscending order by default
Desc-> Descending order.

syntax
--------
select column-name
from table-name
order by column-name;

Q) DISPLAY THE AVERAGE MARKS OF EACH DEPARTMENT CONSIDERING ONLY STUDENTS OLDER THAN 20 YEARS. SHOW DEPARTMENTS WHOSE AVERAGE MARKS ARE GREATER THAN 70 AND       SORT THE RESULTS BY AVG MARKS IN DESCENDING ORDER.

SELECT DEPARTMENT,
AVG(MARKS)AS AVERAGE_MARKS
FROM STUDENTS
WHERE AGE>20
GROUP BY DEPARTMENT
HAVING AVERAGE_MARKS>70
ORDER BY AVERAGE_MARKS DESC
LIMIT 1;

Q) DISPLAY THE TOTAL NUMBER OF STUDENTS IN EACH CITY CONSIDERING ONLY STUDENTS WHOSE MARKS ARE GREATER THAN 70. SHOW CITIES HAVING MORE THAN ONE STUDENT AND SORT BY TOTAL STUDENTS.

SELECT CITY, COUNT(*) AS TOTAL_STUDENTS
FROM STUDENTS 
WHERE MARKS>70
GROUP BY CITY
HAVING TOTAL_STUDENTS>1
ORDER BY TOTAL_STUDENTS DESC;
